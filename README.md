# MySneakerShop
Live Demo — [Ознакомиться](https://bobicentr.github.io/mysneakershop)

# О проекте
E-commerce веб-приложение "Онлайн-магазин кроссовок Sneakershop", написанное на чистом JavaScript, HTML и CSS.  
Позволяет просматривать ассортимент товаров, плавно переходить к разным категориям. Реализована логика корзины: добавление, удаление и подсчёт товаров.
Также имеется страница с оформлением заказа, форма проверяется на корректный ввод данных, присутствует внешняя онлайн карта для выбора адреса. 

# Технологический стек
- HTML5 — структура страниц
- CSS3 — стилизация и адаптив
- Vanilla JavaScript (ES6+) — логика приложения
- Leaflet — карта для выбора адреса
- LocalStorage — хранение корзины на клиенте

# Как установить локально

1. Склонировать репозиторий
```
git clone https://github.com/bobicentr/mysneakershop.git
cd mysneakershop
```

2. Открыть проект через локальный сервер  
(например через Live Server или любой другой способ)

# Ключевые функции
- Логика корзины: добавление, удаление и подсчет товаров  
- Фильтр по категориям с плавной прокруткой к нужной секции  
- Страница оформления заказа  
- Выбор адреса на карте через Leaflet  
- Проверка корректности полей формы (имя, номер телефона)  
- Адаптивный интерфейс под разные устройства
